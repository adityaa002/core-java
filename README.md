## ⚡ Example

### Two Sum — O(n)

```java
Map<Integer, Integer> map = new HashMap<>();

for (int i = 0; i < nums.length; i++) {

    int required = target - nums[i];

    if (map.containsKey(required)) {
        return new int[]{map.get(required), i};
    }

    map.put(nums[i], i);
}
```

**Time:** `O(n)`
**Space:** `O(n)`
